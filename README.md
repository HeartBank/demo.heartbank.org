# demo.heartbank.org

Review site for the `heartbank.org` landing: static artboards (English and Khmer, light plus one dark pass) and the page's motion explainer.

- These are **drawings. They charge nobody** and nothing here is live.
- Unlisted: hidden from search by named crawler in each page, no `robots.txt` (so link previews work).
- Khmer is our own and marked as a placeholder until a native reader approves it.
- Public repo: it holds drawings only. The spec and plan live in a private repo.
- Source of truth is this repo; the index and wall are generated from `canvas.json` (same scripts as `demo.heartbank.ceo`).
- Where a drawing and the memory files disagree, memory is canonical.
